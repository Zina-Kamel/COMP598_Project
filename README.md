# LID in the Wild

This is the codebase for the project LID in the wild done in partial completion of the course - COMP598
The repo is grouped in 2 - 
* Monolingual lid - which details the data gathering and training for the single label lid. As well as evaluation and analysis of baselines and our model on the evaluation datasets
* Codeswitching - which details the data gathering and training of the codeswitch models - FT-openlid and Multi-cs. As well as the evaluation and analysis of the trained models and baselines on the testsplit
